Git回退步骤：
打开终端（项目根目录下）

查看提交历史：

bash
git log --oneline
找到你最后一次正常工作的提交的哈希值（例如 abc1234）。

回退到该版本：

bash
git reset --hard <commit-hash>
例如：git reset --hard abc1234

强制推送（如果已经推送到远程仓库）：

bash
git push --force origin main
重新启动应用：

bash
npm start

bash
git push origin dev （如果是要推送到main，就要把dev改成main）
